# Privacy controls for operational acceptance

Ordinary application events use the reviewed allowlist of fixed action/provider/result codes and correlation/release identifiers. Do not copy credentials, feed URLs, OAuth code/state/verifiers, cookies, authorization headers, raw provider bodies, user IDs/emails, or assignment/course content into logs or acceptance evidence. Error propagation and service-unavailable classification are distinct: an unrelated exception must not produce a false storage-outage metric.

Production persistent logs, invocation metadata and traces remain disabled. Application redaction tests and the controlled preview assessor do not prove platform/framework stored-log behavior or retention. The complete stored-log/privacy gate remains unverified; keep persistence off until that evidence is reviewed. See the retained 7C task 3 privacy capture plan and current deployment configuration.

Local auth fixtures report finite request counts only. They require explicit HTTP loopback fixture bindings; known Turnstile test keys and fixture promotion are rejected by production validation/runtime. A provider-request count proves which controlled transport was exercised, not real provider consent or identity success. Browser trace and response captures from these tests contain synthetic data only; do not reuse that capture pattern with real credentials or identities.

Credential envelopes, onboarding candidates and pending PKCE remain encrypted and scoped to user/purpose/context. Rate history contains derived keys and has bounded expiry cleanup. Expiry alone is not immediate deletion: scheduler delays/backlogs extend retention, and live/uncertain owner metadata is deliberately retained until settlement. Cleanup bounds, scans, FK cascades and activation evidence are documented in [monitoring](monitoring.md#admission-measurements-and-release-handoff) and [incident response](incident-response.md). Account deletion and provider-grant revocation remain separate controls and require real hosted acceptance before launch.
